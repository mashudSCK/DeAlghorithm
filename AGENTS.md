This directory is the DeAlghorithm project workspace.

## Project workflow

- Use Spec Kit for feature specification, planning, and task breakdown. Keep specifications in `specs/` and shared guidance in `.specify/memory/constitution.md`.
- Apply `.agents/skills/ponytail/SKILL.md` to coding tasks at full intensity. Reuse existing code, prefer standard libraries and native features, and build the smallest complete solution.
- Apply `.agents/skills/uncodixfy/SKILL.md` when creating or changing UI. Follow explicit user design requirements first.
- Apply `.agents/skills/caveman/SKILL.md` to chat responses at full intensity. Preserve technical meaning. Write project documents, comments, and commit messages in normal prose.
- User instructions override these defaults. Keep security explanations and multi-step instructions clear.
